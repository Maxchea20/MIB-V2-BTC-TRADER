# Lock 3: Hunt V3

Locked 2026-10-03. This is the switch. It does not rewrite the Hunt.

## Rule

- The 1-hour failed-push box is the switch.
- Box off: the full desktop Hunt trades. The chop does not.
- Box on: a Hunt signal is dropped. The chop trade is the only one allowed.
- Chop entry: a reject of a line, or a turn in the outer quarter before the line is touched.
- Chop stop: a close through the entry line. A wick is not a stop.
- Chop target: the other line.
- One position. If either book is in a trade, the other waits.
- Fee on the chop book is 2 bp a side. The Hunt file is used as recorded.
